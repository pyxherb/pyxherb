## Trivia and Anecdotes

### About the Name

The name "Pyxherb" is from "匚艹" where the "匚" means "box, container" and the "艹" means "grass, herb".

"匚艹" imitates the shape of "C++".

"CodesBuilder" is an old name which was obsoleted in 2023.
